# Agent notes

- Read [.github/CONTRIBUTING.md](.github/CONTRIBUTING.md) before any change: it is the single source for the layout, the change
  loop and the rules.
- Read [docs/design.md](docs/design.md) before changing how a component looks or is structured.
- Read [docs/recipe.md](docs/recipe.md) before converting or adding a component.
- Read [tests/browser/README.md](tests/browser/README.md) before writing or moving a browser spec.
- While iterating, run the affected part tests (`pnpm test:parts <name>`) and page specs
  (`pnpm exec playwright test <name>`). Finish with `pnpm check` green, and
  with `site/public/r/` rebuilt and included if an item's install changed.
- When a change touches anything an item ships, bump the item and write its changelog entry in its `.meta.ts`
  (breaking changes use the template in CONTRIBUTING), then run `pnpm versions:lock` and `pnpm changelog`.
- Read [REVIEW.md](REVIEW.md) before opening a pull request, and check the change against it.
- Write screenshots, logs and scratch files to `.artifacts/`. The repository holds source and lasting docs only.
- `site/AGENTS.md` is generated by Next.js and covers the Next.js version only.
